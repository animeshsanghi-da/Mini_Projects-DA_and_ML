# Habit Tracker Project

This repository contains a simple habit tracking dataset and a Python-based data cleaning pipeline. This project is designed to transform raw log data into a clean format suitable for visualization in tools like Excel, Power BI, or Tableau.

## Project Structure

* **`habit_data.csv`**: The raw data file containing daily logs for habits, including categories, status, duration, mood, and energy levels.
* **`data_cleaning.py`**: A Python script that standardizes dates, fills missing numeric values (using the median), imputes categorical defaults, and ensures consistent text formatting.
* **`cleaned_habit_data.csv`**: The output file generated by the cleaning script, ready for analysis.

## Getting Started

### Prerequisites

To run the data cleaning script, you will need Python installed on your machine along with the `pandas` library.

You can install `pandas` using pip:

```bash
pip install pandas
```

### Running the Pipeline

1. Ensure your raw data is saved in the same directory as the script.
2. Run the cleaning script via your terminal:

```bash
python data_cleaning.py
```

3. The script will automatically output a new file named `cleaned_habit_data.csv`.

## Data Processing Details

The `data_cleaning.py` script performs the following operations to ensure data integrity:

* **Date Conversion**: Converts the date string column into datetime objects.
* **Imputation**:
    * Numerical columns (`Duration_Minutes`, `Mood_Score`) are filled with the median to maintain statistical balance.
    * Categorical columns (`Energy_Level`, `Notes`) are filled with default values ("Medium" and "No notes" respectively).
* **Normalization**: Strips whitespace and capitalizes the `Status` column for consistent filtering in dashboards.
