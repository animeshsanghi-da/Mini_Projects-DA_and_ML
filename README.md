## 📂 Repository Structure
Below is a directory summarizing each project with direct links to their respective codebases.

### [01. Python Email Automation System](./01_Email_Automation)
* Automates the sending of personalized mass emails tailored for professional outreach campaigns.
* Built securely using Python's `smtplib`, `csv`, and `getpass` to dynamically inject recipient details into email templates.

### [02. Business Name Generator](./02_Business_Name_Generator)
* A lightweight CLI tool that brainstorms unique, professional business names based on core keywords.
* Utilizes combinatorial logic with curated adjectives and suffixes, ensuring unique results via Python sets.

### [03. Bluetooth LE Device Finder](./03_Bluetooth_Finder)
* An asynchronous Bluetooth Low Energy (BLE) device scanner built with the `bleak` library.
* Retrieves and lists nearby device names and unique MAC/UUID addresses in real-time.

### [04. QR Code Generator & Scanner](./04_QR_Code_Generator)
* Generates custom, scannable QR codes from textual data or URLs.
* Uses OpenCV and Pyzbar to scan and decode physical QR codes via a live webcam feed or static image files.

### [05. Bluetooth Attendance System](./05_Bluetooth_Attendance)
* Automates attendance tracking by detecting nearby BLE devices and matching them against a known database.
* Built using `bleak` for asynchronous scanning and `pandas` for real-time CSV log updates.

### [06. Habit Tracker Data Pipeline](./06_Habit_Tracker)
* A Python-based ETL pipeline utilizing Pandas to clean and standardize daily habit logs.
* Handles date conversion, missing value imputation, and categorical normalization to prepare data for downstream BI dashboards.

### [07. CRM Dashboard Data Processing](./07_CRM_Dashboard)
* An automated script processing raw Customer Relationship Management (CRM) data to ensure structural integrity.
* Engineers new analytical features—like churn risk based on contact frequency—for seamless integration into Power BI.

### [08. Blinkit Delivery Dashboard](./08_Blinkit_Dashboard)
* An end-to-end data workflow transforming raw grocery delivery data into a professional Power BI dashboard.
* Visualizes critical KPIs including total revenue, category performance, and average sector delivery times.

### [09. Zomato Analytics Dashboard](./09_Zomato_Dashboard)
* Analyzes food delivery transactions to extract actionable insights on vendor performance and service efficiency.
* Highlights the business trade-offs between ticket sizes and delivery speed using Python data cleaning and Power BI.

### [10. Hospital Patient Dashboard](./10_Hospital_Patient_Dashboard)
* A comprehensive healthcare analytics project tracking operational metrics like patient wait times and treatment costs.
* Utilizes a Python ETL script to calculate "Length of Stay" and handles missing records before rendering KPIs in Power BI.

### [11. SQL Inventory Management](./11_Inventory_Management)
* A structured relational database framework featuring complete DDL/DML scripts for stock and supplier management.
* Includes advanced analytical queries for automated low-stock alerts, financial inventory valuation, and stale asset tracking.

### [12. Call Center Operational Database](./12_Call_Center_Database)
* A MySQL analytics database designed to track and optimize call center interactions.
* Features queries to evaluate agent CSAT scores, pinpoint high-escalation periods, and perform root-cause analyses on pending issues.

### [13. Restaurant Sales Exploratory Data Analysis](./13_Restaurant_Sales_Analysis)
* Follows the 6-stage data analysis process (Ask, Prepare, Process, Analyze, Share, Act) to uncover retail trends.
* Uses Pandas and Seaborn to analyze peak operational hours, menu item sentiment, and payment method distributions.

### [14. AI Resume Screening System](./14_AI_Resume_Screening)
* An NLP and Machine Learning pipeline that automatically classifies resumes into professional categories.
* Implements TF-IDF vectorization and a K-Nearest Neighbors (KNN) classifier, optimized with `joblib` for rapid inference.

### [15. Linear Regression Master Portfolio (30 Models)](./15_Linear_Regression_30)
* An extensive benchmarking sandbox evaluating 30 distinct Linear Regression iterations on housing data.
* Analyzes the mathematical impact of feature scaling, polynomial complexity boundaries, and Ridge/Lasso regularization.

### [16. Logistic Regression Benchmark (30 Models)](./16_Logistic_Regression_30)
* An automated programmatic framework evaluating classification accuracy across multiple datasets.
* Uses controlled nested loops to uniformly test preprocessing constraints and hyperparameter tuning (solvers and C-values).

### [17. Support Vector Machine (SVM) Suite (30 Models)](./17_SVM_30)
* A dynamic experimental notebook tracking SVM performance across low, medium, and high-dimensional datasets.
* Evaluates non-linear boundaries by tuning Kernel functions, Gamma distributions, and regularization strengths.

### [18. K-Nearest Neighbors (KNN) Benchmark (30 Models)](./18_KNN_30)
* An exhaustive study mapping distance metrics (Euclidean, Manhattan, Cosine) against variable K-values.
* Implements strict Scikit-Learn Pipelines to prevent data leakage during dimensionality reduction (PCA) and scaling.

### [19. Student Placement Prediction Pipeline](./19_Student_Placement_Prediction)
* A production-ready Random Forest classifier designed to predict placement success based on academic and soft-skill metrics.
* Features Stratified 5-Fold Cross-Validation, feature importance explainability, and a live deployment inference module.

### [20. Electricity Consumption Time-Series Forecasting](./20_Electricity_Consumption_Prediction)
* A regression model predicting grid load based on environmental and temporal inputs (heatwaves, holidays).
* Adheres strictly to chronological index-based splits to prevent temporal data leakage, ensuring robust real-world forecasting.

### [21. Course Recommendation Engine](./21_Course_Recommendation_System)
* A content-based recommendation system matching users to e-learning curriculum using NLP metadata.
* Calculates structural Cosine Similarity matrices while actively preventing self-recommendation and data-loss edge cases.

### [22. AI Social Media Content Generator](./22_Social_Media_Generator)
* A lightweight Python utility powered by the Google Gemini API to draft platform-optimized social media posts.
* Features real-time text streaming and secures API credentials via environment variables.

### [23. Automated Resume Builder](./23_Resume_Builder)
* Uses the Google Gemini API to merge user details with predefined structural templates.
* Generates clean, well-formatted, and professional text files ready for word processor ingestion in seconds.

### [24. Gemini-Powered PDF Chatbot](./24_PDF_Chatbot)
* A Retrieval-Augmented Generation (RAG) web application built with Streamlit and Gemini 1.5 Pro.
* Extracts document embeddings into a FAISS index, allowing users to accurately query their uploaded PDFs.

### [25. Legal Document Assistant](./25_Legal_Doc_Assistant)
* A secure Python CLI tool designed to summarize contracts, extract compliance deadlines, and flag ambiguous phrasing.
* Engineered with strict system instructions via the Gemini API to maintain analytical consistency.

### [26. Terminal AI Chatbot](./26_AI_Chatbot)
* Transforms the standard command line into an interactive conversational agent using Gemini 1.5 Flash.
* Implements robust state memory for follow-up context and utilizes defensive `try/except` error handling.

### [27. Serial Port LED Automation](./27_LED_Bulb_Automation)
* Demonstrates Machine-to-Machine (M2M) communication by bridging a Python script with an Arduino microcontroller.
* Uses the `pyserial` library to toggle hardware components directly from a computer terminal.

### [28. AI Career Advisor App](./28_Career_Advisor)
* An interactive Streamlit application serving as an automated career coach.
* Assesses user skills against target roles to output a strategic 3-month preparation timeline and interview guide.

### [29. LangChain Autonomous Data Analyst](./29_AI_Data_Analyst)
* An agentic LLM workflow that interprets natural language queries to manipulate datasets without manual coding.
* Autonomously writes and executes Pandas operations to summarize stats and generate matplotlib visualizations.

### [30. MLOps: Restaurant Sales Deployment](./30_Restaurant_Sales_MLOps)
* Showcases an end-to-end MLOps lifecycle by wrapping a machine learning inference model in a Streamlit interface.
* Containerized using Docker to ensure portable, scalable, and isolated deployment environments.

### [31. GCP Cloud Deployment Pipeline](./31_Cloud_Deployment)
* A CI/CD configuration project detailing the deployment of a containerized application to Google Cloud Run.
* Automates build steps via `cloud_config.yaml`, Artifact Registry, and Cloud Build.

### [32. Number Guessing Logic Game](./32_Python_Logic_Game-Guess_the_number)
* An interactive command-line application using the `random` module to generate hidden targets.
* Features loop-based dynamic hint generation and out-of-bounds input validation.

### [33. Mathematical Rock-Paper-Scissors (Snake Water Gun)](./33_Python_Logic_Game-Snake_water_gun)
* A logic-based re-theme of the classic game playable in the terminal.
* Eliminates heavy `if/else` conditional chains by determining win/loss states through numerical dictionary mapping.

### [34. Python Text-to-Speech Engine](./34_Python-Text_to_Speach_Engine)
* A local voice synthesizer using the `pyttsx3` library.
* Supports dual modes, allowing the engine to read both real-time console input and pre-written local text files.
