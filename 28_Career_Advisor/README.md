# 🚀 AI Career Advisor

This project is an AI-powered Career Coach application built using **Streamlit** and the **Google Gemini API**. It acts as a personal mentor, helping users bridge the gap between their current skill set and their desired career trajectory.

## 💡 Features
* **Personalized Analysis**: Analyzes your current skills, experience, and education.
* **Goal-Oriented**: Tailored feedback based on your specific career target (e.g., Junior Data Analyst, Frontend Developer).
* **Structured Roadmaps**: Provides:
    * Identified skill gaps.
    * Recommended projects to build.
    * A 3-month strategic preparation timeline.
* **Interview Prep**: Offers specific interview tips for the chosen role.

## 🛠 Tech Stack
* **Python**: Core programming language.
* **Streamlit**: For the interactive web interface.
* **Google Generative AI (Gemini)**: Powers the intelligence behind the career advice.

## 🚀 How to Run

1. **Prerequisites**: Ensure you have Python installed and an API key from [Google AI Studio](https://aistudio.google.com/).

2. **Navigate to the folder**:
```bash
cd 28_Career_Advisor
```

3. **Install dependencies**:
```bash
pip install -r requirements.txt
```

4. **Run the application**:
```bash
streamlit run app.py
```

## 🔑 Usage
1. Once the app launches in your browser, look at the **Sidebar**.
2. Enter your **Google Gemini API Key**.
3. Fill in your **Profile Details** (Experience, Skills, Education).
4. Define your **Career Goal**.
5. Click **"Get Career Advice"** to generate your roadmap.

## 📂 Project Structure
* `app.py`: The main Streamlit application script.
* `requirements.txt`: Dependencies required to run the project.
* `README.md`: Documentation for the project.
